# web3Satoshi

A modern Web3 dashboard for wallet management, transaction sending, token swaps, and portfolio tracking.

## Features

- Wallet connection using RainbowKit and Wagmi
- Send native token transactions
- Simulated token swap panel
- Portfolio summary cards
- Recent activity feed
- EVM-ready architecture

## Getting started

1. Install dependencies:

   npm install

2. Start the development server:

   npm run dev

3. Build for production:

   npm run build

## Notes

This app is designed as a polished demo interface for a Web3 wallet tool. For production use, replace the demo WalletConnect project ID and connect the swap flow to a live DEX/router and token metadata source.
